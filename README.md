# FESORIA

Official website for **FESORIA — One universe. Infinite worlds.**

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel. The default settings are enough.

- EP02 — Neo Tokyo
